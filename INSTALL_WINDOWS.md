# Device Tracker — інструкція для Windows

Працює на Windows 10 і Windows 11.

---

## Крок 1. Перенести папку програми на Windows

Скопіюйте всю папку `SEB` на компʼютер з Windows (флешка, Google Drive, архів zip — як зручно).
Покладіть її в постійне місце, наприклад `C:\Users\<ваше імʼя>\Documents\DeviceTracker`.

Потрібні файли:

| Файл | Для чого |
|---|---|
| `device_tracker.py` | сама програма |
| `run_windows.bat` | запуск програми |
| `run_windows_debug.bat` | запуск з вікном помилок (якщо щось не відкривається) |
| `create_shortcut_windows.bat` + папка `tools` | ярлик на робочий стіл |
| `build_windows.bat` | зібрати один файл `DeviceTracker.exe` (не обовʼязково) |

> Якщо завантажили папку з інтернету (Google Drive, Telegram), Windows може блокувати bat-файли.
> Клік правою кнопкою на файлі → **Властивості** → внизу галочка **Розблокувати** → OK.

---

## Крок 2. Встановити Python (один раз)

1. Відкрийте https://www.python.org/downloads/ і натисніть жовту кнопку **Download Python 3.x**.
2. Запустіть завантажений файл.
3. **ВАЖЛИВО:** внизу першого вікна поставте галочку **Add python.exe to PATH**.
4. Натисніть **Install Now** і дочекайтесь кінця, потім **Close**.

Перевірка (не обовʼязково): натисніть `Win + R`, введіть `cmd`, Enter, і в чорному вікні напишіть:

```
py --version
```

Має показати щось на зразок `Python 3.13.1`.

---

## Крок 3. Запустити програму

Двічі клікніть **`run_windows.bat`** — відкриється вікно Device Tracker.

Якщо Windows покаже синє вікно **«Windows protected your PC»** → **More info** (Докладніше) → **Run anyway** (Усе одно запустити).

---

## Крок 4. Ярлик на робочому столі (зручно)

Двічі клікніть **`create_shortcut_windows.bat`** — на робочому столі зʼявиться ярлик **Device Tracker**.
Далі запускайте програму з нього.

Ярлик можна закріпити: правою кнопкою → **Закріпити на панелі завдань** (Pin to taskbar).

---

## (Не обовʼязково) Один файл DeviceTracker.exe

Якщо хочете програму одним файлом, який працює **без Python** (наприклад, щоб перенести на інший компʼютер):

1. Двічі клікніть **`build_windows.bat`** (потрібен інтернет, 1–3 хвилини).
2. Готовий файл буде тут: `dist\DeviceTracker.exe`.
3. Його можна скопіювати куди завгодно і запускати подвійним кліком.
4. Після збірки запустіть `create_shortcut_windows.bat` ще раз — ярлик почне відкривати вже `.exe`.

> Антивірус іноді помилково підозрює самозібрані `.exe`. Якщо так — додайте файл у винятки,
> або просто користуйтесь `run_windows.bat` (програма та сама).

## Де зберігаються дані

Усе зберігається автоматично після кожної дії — нічого натискати не треба, дані залишаються після вимкнення компʼютера.

Папка з даними: `%APPDATA%\DeviceTracker`

Як відкрити: в програмі **More → Open data folder**, або `Win + R` → вставити `%APPDATA%\DeviceTracker` → Enter.

- `devices.db` — уся база (дні, прилади, статуси, налаштування)
- `backups\` — автоматична копія бази за кожен день (останні 30)
- `error.log` — зʼявляється, лише якщо була помилка

### Перенести дані з Linux на Windows

1. На Linux файл лежить тут: `~/.local/share/DeviceTracker/devices.db`
2. Закрийте програму на Windows.
3. Скопіюйте `devices.db` у `%APPDATA%\DeviceTracker\` (замініть файл).
4. Запустіть програму.

Так само можна переносити і назад, або між двома компʼютерами з Windows.

### Демо-дані

На новому компʼютері база порожня. Щоб подивитись, як усе виглядає: **More → Add demo data**.
Прибрати: **More → Remove demo data** (ваші записи не зачіпаються).

## Як користуватись (коротко)

- **Today** — відкрити сьогоднішній день. **+ New day...** — будь-яка дата.
- Ввести номер → вибрати статус → **Enter** (сканер штрихкодів теж працює).
- Великий чекбокс справа — «віддав». **Пробіл** — відмітити всі виділені рядки.
- **1–9** — поставити статус виділеним рядкам. Права кнопка миші — меню.
- **Ctrl+F** — пошук за номером (працює і на українській розкладці), **Enter** — перейти до знайденого.
- **Statuses...** — свої статуси та кольори.
- **☀ Light / ☾ Dark** — світла / темна тема.
- **Polish Corrector** — виправлення польських текстів (потрібен інтернет).

## Якщо щось не працює

| Проблема | Що робити |
|---|---|
| Після подвійного кліку нічого не відкривається | Запустіть `run_windows_debug.bat` — у чорному вікні буде текст помилки. Зробіть скріншот. |
| «Python was not found» або відкривається Microsoft Store | Python не встановлений або без галочки PATH. Перевстановіть (Крок 2) з галочкою **Add python.exe to PATH**. Також: Пуск → «Manage app execution aliases» (Псевдоніми виконання програм) → вимкніть `python.exe` і `python3.exe`. |
| `No module named tkinter` | Запустіть інсталятор Python ще раз → **Modify** → галочка **tcl/tk and IDLE** → Next → Install. |
| Вікно Windows блокує bat-файл | Див. Крок 1 (Розблокувати) або Крок 3 (Run anyway). |
| Polish Corrector: «Connection error» | Немає інтернету або сервіс тимчасово недоступний. Спробуйте пізніше. |
| Помилка під час роботи | Програма покаже повідомлення, деталі — у `%APPDATA%\DeviceTracker\error.log`. |

Відомі дрібниці Windows: контекстні меню (права кнопка миші) завжди світлі, навіть у темній темі, — так малює їх сама Windows.

---

## Оновлення програми

Замініть файл `device_tracker.py` новою версією. Дані (`%APPDATA%\DeviceTracker`) при цьому не змінюються.
Якщо користуєтесь `.exe` — після заміни запустіть `build_windows.bat` ще раз.
